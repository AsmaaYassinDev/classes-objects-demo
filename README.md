# Classes and Objects Practice

This repository contains practice exercises for learning the fundamentals of Object-Oriented Programming (OOP) in C#.

## Project Contents

This project is broken down into three main parts:

* **Question 1 (`q1.txt`):** A non-technical explanation of Classes vs. Objects using an everyday analogy (the factory design vs. the physical car).
* **Question 2 (`q2.txt`):** An explanation of why Classes are better than using separate variables, using a "Student File Folder" analogy.
* **Question 3 (`q3_design.txt` & `Program.cs`):** The design and implementation of a `BankAccount` class.

## The Bank Account Program

The C# program in `Program.cs` demonstrates how to:
1. Create a blueprint (`BankAccount` class).
2. Instantiate unique objects from that blueprint (Sarah's account and John's account).
3. Use methods (`Deposit()` and `Withdraw()`) to change the data inside those specific objects independently. 

## How to Run
1. Open `ClassVsObjectDemo.sln` in Visual Studio.
2. Press the **Start** button at the top to run the console application.
