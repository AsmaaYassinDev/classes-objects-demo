# Classes & Objects — Live Coding
 
This repository contains the live-coding example for an introduction to
**Classes and Objects**.
 
## What This Demo Covers
 
The example uses a simple `Cake` scenario to demonstrate:
 
- The difference between a **Class** and an **Object**
- **Fields** for storing object data
- A **Constructor** for setting initial values
- **Methods** for defining object actions
- Creating multiple objects from the same class
## Before & After
 
The demo first shows the same problem solved **without classes** — separate
variables and near-identical functions for each cake. It then rewrites the
same logic **using a `Cake` class**, so you can see the contrast directly:
one blueprint, many objects, each with their own data.
 
## Example
 
The `Cake` class acts as a blueprint. Each object created from it — like
`cake1` or `cake2` — has its own values for flour, sugar, and eggs.
 
## How to Run
 
```bash
dotnet run
```
 
## Context
 
Built to accompany a micro-teach session on Classes & Objects for
first-year computing students.
